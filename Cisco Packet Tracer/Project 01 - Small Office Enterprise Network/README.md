# Project 01 - Small Office Enterprise Network

## Objective
Design and configure a small office network with two departments connected through a Layer 3 router.

## Technologies
- Cisco Packet Tracer
- Static IP Addressing
- Layer 2 Switching
- Layer 3 Routing
- VLAN Management Interface
- Default Gateway Configuration

## Skills Demonstrated
- Router configuration
- Switch configuration
- Static IP addressing
- Inter-network routing
- Network documentation
- End-to-end connectivity testing

## Devices Used
- 1 Cisco 2911 Router
- 2 Cisco 2960 Switches
- 18 PCs
- 1 Server
- 1 Network Printer

## Result
Successfully configured communication between both departments using static routing and verified connectivity with ping tests.
